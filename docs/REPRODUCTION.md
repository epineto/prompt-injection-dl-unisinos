# Reproducing the report's results in the lab

[Versão em português](REPRODUCAO.md) · [README](../README.md)

This guide maps each table, figure and number of Deep Learning Assignment 02 to the lab section (<https://epineto.github.io/prompt-injection-dl-unisinos/>) and gives the expected values. Reference values come from `reference/resultados/` (generated by `reference/python/trabalho2_dl.py`) and are in `data/resultados.json`. Click **EN** in the header for English.

## Tolerances
Browser training uses He initialization and mulberry32 shuffling; PyTorch uses a different initialization and generator. **Deterministic items match** (tokenization, TF-IDF, forward, gradients, one step of each optimizer, the pre-trained model; see `npm test`) and **sampling-dependent items match statistically**: expect values within the seed deviation, not identical ones.

## One-minute shortcut
1. `#testar`: "Classic injection (EN)" example → probability ≈ 99.4% (in Portuguese, "Classic injection (PT)": 99.8%).
2. `#treinar`: **Train** with the default values (bilingual, takes seconds) → bilingual F1 ≈ 0.92; then "EN/DE only" and "PT only" to see hypothesis H4.
3. `#otimizadores`: **Compare**, with and without "Adam with lr 0.01" → RMSProp (and Adam with rate 0.01) reach the minimum in few epochs; they do not have lower loss.
4. `#backprop`: **Train** → the loss falls and the boundary separates XOR.

## Bilingual data and the translation
`data/deepset_pt.json` is the aligned Brazilian-Portuguese translation of deepset/prompt-injections (546 training and 116 test texts), used by `reference/python/injecao.py` and by the notebook (raw URL of the repository, `https://raw.githubusercontent.com/epineto/prompt-injection-dl-unisinos/main/data/deepset_pt.json`). ```
